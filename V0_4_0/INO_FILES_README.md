# Hinweis zu den INO-Dateien

## Aktuelle Version

**V0_4_3_A.ino** ist die aktuelle und aktive Version des ESP32 Solar Monitor.

## Veraltete Versionen

- `V0_4_0.ino` - Alte Version (nur zu Referenzzwecken aufbewahrt)
- `V0_4_1.ino` - Alte Version (nur zu Referenzzwecken aufbewahrt)

Diese älteren Versionen sollten nicht mehr verwendet werden und können in zukünftigen Versionen entfernt werden.

## Empfehlung

Für neue Entwicklungen und Deployments verwenden Sie bitte nur **V0_4_3_A.ino**.
